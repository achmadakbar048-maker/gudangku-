# GudangKu

Aplikasi sistem gudang (inventori, mutasi barang, penjualan, laporan) dengan Supabase sebagai database bersama untuk semua akun/gudang.

## Menjalankan di komputer sendiri (opsional, untuk coba-coba dulu)

Butuh Node.js (unduh di https://nodejs.org, pilih versi **LTS**).

```
npm install
npm run dev
```

Lalu buka alamat yang muncul di terminal (biasanya `http://localhost:5173`).

## Publish ke internet

Lihat panduan lengkap "Cara Publish & Update Aman.md" yang dikirim bersama project ini.
